## 발견한 오류와 수정

1. **CSV 중복 빈 헤더로 값 유실**: `csv.DictReader`가 앞 열의 `N`·날짜 값을 덮어써 법령 자료 3청크에 실제 필드가 빠졌다. 위치 기반 CSV 읽기로 고치고 정상 CSV의 기존 본문·ID 호환성을 검사했다. 해당 원천의 새 6청크를 현재 질의용 bge-m3로 재임베딩했다. 1,024차원·전체 입력 해시·고정 모델 digest를 기록했고 과거 벡터의 모델 이력은 미확인으로 유지했다.
2. **원본 손실 없는 교체**: 기존6의 본문·벡터와 전체 행을 파일 및 DB archive로 보존하고, 단일 transaction의 행 해시 비교 후 새6 삽입/기존6 SUPERSEDED 전환을 했다. 부모와 별도 에이전트가 실제 DB 및 원문 100행을 다시 대조했다. 실제 롤백을 실행했다고 주장하지 않으며 절차는 별도 문서에 남겼다.
3. **원문 조회 연결 복구**: 컨테이너·staging 경로846개, HWP2,566 및 워크시트472의 감사 어댑터, archive member 경로 등을 보완했다. 경로는 전체 원본 해시가 맞는 경우만 연결했다. 원문 파일은 변경하지 않았다.
4. **좌표 표기 경고**: 명시 좌표 후보6,672쌍 중 같은 `35도 02분 60초` 표기가 3청크에 있었다. 이를 독립된 3개 현실 위치 오류로 세지 않고 원문 경고로 보존했다. 임의 올림·좌표 보정 없이 실제 답변에서 경고하고 위치 권위를 부여하지 않는다.
5. **검색·답변 보호**: 현재 청크 ID·본문·출처가 감사 기록과 모두 같을 때만 원문 확인을 표시한다. 불일치와 현재 SUPERSEDED는 coastal 및 벡터 주/후퇴 검색과 직접 발췌에서 제외한다. 제외 후 정상 후보가 부족하지 않도록 제한된 추가 후보 조회를 적용했다. 수정된 본문을 과거 ID만으로 차단하지 않는다.
6. **정상 지명 조회 복구**: 검증된 2022 해양지명 CSV1,146행과 실제 DB가 일치하는 경우 원천 수록 객체 검색을 허용한다. 동일 읽기 전용 transaction에서 다시 확인하고 실행 결정은 ExecutionValidator만 한다. 실제 해역 전체의 지리 완전성은 UNKNOWN이며 부재를 보증하지 않는다.
