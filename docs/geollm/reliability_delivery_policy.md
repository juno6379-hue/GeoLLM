# GeoAgent 신뢰성 정책: 운영 구현과 논문 평가 분리

기준일: 2026-11-01. 사용자 지정 `CODEX_GeoLLM_GeoAgent_Reliability_Cases_Judgment_Policy_KR.md`를 구현·감사 기준으로 사용한다. 문서의 예시 수치, 상태명, 모델 강점 후보는 검증된 운영 설정이나 실험 결과가 아니다.

## 두 경로와 완료 기준

| 구분 | 운영 시스템 | 논문 실험 |
|---|---|---|
| 목적 | 일반 질의에서 잘못된 실행·답변 방지 | 동일 조건에서 방법별 효과 측정 |
| 정책 위치 | `docs/geollm/`, 운영 schema/registry | `research/marine_geollm_scie/reliability/`, protocol |
| 입력 | 실제 사용자·지도·원천의 현재 문맥 | 동결 질문·snapshot·GOLD·fault set |
| 변경 | 일반화된 오류 재현 후 최소 수정 | 새 manifest와 run으로 조건 고정 |
| 검증 | 단위 회귀 + 실제 API 정상/부정 사례 + 원천 검증 | 독립 SQL/GIS oracle + 동결 hash + 8방법 실행 + 항목별 채점 |
| 완료 | 해당 기능의 종단 검증 증거가 있을 때 | 기대 관측 집합·검사·보고서가 모두 존재할 때 |

연구 폴더의 정책 레지스트리는 운영 설정으로 자동 import하지 않는다. 운영 코드는 질문 ID, 정답 객체 ID, 연구 전용 부산항 polygon을 알지 못해야 한다. 연구에서 관측한 버그는 운영 회귀 사례로 전환할 수 있지만, 이후 해당 사례는 개발 사례이며 독립 holdout으로 주장하지 않는다.

## 변경·검증 절차

1. 원본 질의/응답/실행 로그와 당시 source hash를 보존한다.
2. 원인을 의도, 입력, 원천 범위, 설정, 실행, 근거, 완료 판정으로 분리한다. 자료가 없는 상황을 모델 오류로 바꾸지 않는다.
3. 변경 종류를 `product change`, `research-only instrumentation`, `evaluation policy`로 지정한다.
4. 운영 수정은 benchmark에 특화하지 않고 정상/부정 회귀로 검증한다. 실행 권한은 ExecutionValidator만 부여한다.
5. 주 에이전트가 diff·테스트·실제 API 결과를 통합 검토한다. 에이전트 보고만으로 완료 처리하지 않는다.
6. 운영 코드 또는 연구 실행 코드가 바뀌면 새 source fingerprint로 전체 비교를 실행한다. 이전 결과는 원본 이력으로 남긴다.

## 고정해야 할 의미

- `nearest`에 숨겨진 반경을 추가하지 않는다. 범위 밖 데이터는 실세계 최근접 정답이 아니다.
- 기본 반경은 기능별 승인 정책과 provenance가 있어야 한다. 정책 문서의 1km 예시를 전역 기본값으로 적용하지 않는다.
- `SUCCESS_EMPTY`, 범위 미확인/범위 밖, SQL 실패를 구분한다. 정상 SQL 실행은 실세계 부재를 증명하지 않는다.
- 공간 결과, 객체별 근거, 비교/설명 등 필수 하위작업을 각각 판정한다. 일부 산출물로 전체 완료를 표시하지 않는다.
- 복구 전후 Feature·공간 연산·기준기하·거리·원천·권한을 비교한다. 실행 성공과 의미 보존을 모두 만족해야 완전한 복구 성공이다.
- B3/B4/P0/H의 초기 계획을 공유하며, P0 컴파일은 누락을 채우거나 의미를 고치지 않는다. 운영의 명시적 문맥 해소와 연구 P0 무손실 컴파일을 혼동하지 않는다.

## 결과를 읽는 순서

[실험 결과 위치 안내](../../research/marine_geollm_scie/RESULTS_INDEX_KR.md)에서 완료된 이전 실험과 준비 중인 새 실험을 구분한다. 평균만 제시하지 않고 오류 유형·질의 조건·측정/미측정 분모를 함께 보고한다. 단위 테스트 통과는 모델 비교 결과가 아니며, 기계 계약 통과는 인간 의미 정확도가 아니다.

전체 시스템 완료는 현재 선언하지 않는다. coverage 원천의 충분성, 영역/최근접 도구, 복합 산출물, 실제 객체와 FC 연결, recovery 및 운영 SLO 등은 각각 실증된 범위만 완료로 기록한다.
